# W–O 简化参考模型与四模型预筛选包

本包先解决“W 第一配位壳全部为 O、尽快得到可追溯的理论 XAS 参照”这一问题。**第一阶段不需要新的 DFT 优化；第二阶段的催化剂候选从 12 个缩减为 4 个，并改为局域松弛预筛选。** 原补算包和已有计算结果没有改写。

当前交付的是结构、计算输入和脚本；本机没有执行新的 FEFF 或 DFT 物理计算。`preview/` 是原子坐标预览，不是已算出的 XAS。

## 1. 建议采用的两阶段方案

| 阶段 | 模型 | 用途 | 新 DFT 优化 |
|---|---|---|---|
| 先做 | 完整 α-[PW₁₂O₄₀]³⁻，53 个原子 | W–O 氧配位的有限簇 FEFF 几何参照 | 不需要 |
| 查看结构 | 从上述参照截出的 W₁O₆，7 个原子 | 看第一配位壳和真实键长 | 不进行；不是完整稳定分子 |
| 后续预筛选 | 4 个 W–O–Co/Fe 载体候选，79–87 个原子 | 比较羟基化、Co 去质子化、EG@W、EG@Co | 4 个局域松弛任务 |

不要从 WO₆ 片段生成整套定量 XANES：它截断了桥氧外侧的成键伙伴和多重散射环境。也不要用完整 PW₁₂ 的光谱代替 W 单原子/CoFe LDH 的光谱；两者第一壳同为 O，但第二壳及更远环境不同。

## 2. 磷钨酸根参考模型来自哪里

参考几何取自 Deblonde 和 Colliard 的原始晶体学论文：

- DOI：<https://doi.org/10.1107/S2056989024005565>；CCDC 2361833。
- 公开坐标表：<https://journals.iucr.org/e/issues/2024/07/00/ox2004/index.html>。
- 按公开分数坐标、晶胞 a = 22.9963 Å 和空间群 Fm−3m 展开，再提取单个完整 P₁W₁₂O₄₀。原始 CIF 下载不可用，因此交付 CIF 是从公开表格重建的结构文件，并非作者原始 CIF。
- 去除了盐晶体的 Cs/Tl/Cl 外围组分，没有引入这些元素到催化剂。没有加氢、对离子或溶剂，也没有称它为已优化的游离磷钨酸。

12 个 W 属同一晶体学等价位置。每个 W 的六个 O 近邻距离为 **1.7141、1.9179 × 2、1.9420 × 2、2.3468 Å**。最近 W–W 距离约 **3.3588 Å**。完整结构有 12 个端氧、24 个桥氧和 4 个与中心 P 相连的氧。

`references/alpha_PW12O40_crystallographic.xyz` 是 FEFF 的坐标来源。CIF 的 30 Å 盒子仅用于存储和打开查看，**不允许按周期晶体复制到 FEFF 模型**。代表吸收原子为 XYZ 零基索引 1 的 W。

## 3. 第一阶段：无需 DFT 的参考计算

复用上一补算流程的 FEFF10 和 Python/Larch 环境。`requirements.txt` 记录后处理依赖；已有无头环境不必重复安装 GUI 依赖。结构输入生成和 FEFF 调用脚本只需要标准 Python。

```bash
# 在包的根目录，核查/重新生成输入
python scripts/prepare_reference_feff.py
```

`jobs_reference/manifest.json` 列出四个任务：

| 任务索引 | 配置 | 目的 |
|---:|---|---|
| 0 | small/xanes | 6 Å SCF/FMS 半径的 XANES |
| 1 | small/exafs | 6 Å SCF 半径的 EXAFS |
| 2 | full/xanes | 全分子 SCF/FMS 的 XANES |
| 3 | full/exafs | 全分子 SCF 的 EXAFS |

四个输入均保留完整的 53 原子列表；小半径配置仅缩小电子势/FMS 处理范围。全分子半径约 8.85 Å，可覆盖从代表 W 出发的全部分子原子。只需一个代表 W，毋须重复计算十二个等价位点。

在 `config_reference.json` 中设置平台实际 FEFF 完整运行器的命令数组，例如 `["/actual/path/to/run_feff10.sh"]`。完整运行器应按官方顺序执行 FEFF 各模块，不能只启动其中一个模块。队列、账户、内存和并发数在 `hpc/` 的作业数组模板中设置。在计算节点中也可调用 `scripts/run_reference_job.py --task-index 0`（依次更换任务索引）。不要在登录节点运行 FEFF 物理计算。任务完成状态和输出校验由运行脚本记录。

FEFF XANES 使用相对能量 EGRID −160…130 eV、步长 0.5 eV，并检查原生输出是否覆盖 W L₃ 边 **10100–10300 eV**。EXAFS 计算到 k = 14 Å⁻¹。覆盖不足必须保留原输出并重新计算，不能补零、外推或移动单条谱线来凑范围。

### TXT 和图片导出

四个 FEFF 任务完成并检查后，分别导出 full 与 small 配置：

```bash
python scripts/postprocess_reference.py \
  --xanes jobs_reference/full/xanes/xmu.dat \
  --exafs jobs_reference/full/exafs/chi.dat \
  --output results/reference_full

python scripts/postprocess_reference.py \
  --xanes jobs_reference/small/xanes/xmu.dat \
  --exafs jobs_reference/small/exafs/chi.dat \
  --output results/reference_small
```

输出包括原生 μ(E)、χ(k)、k¹/k²/k³χ(k)、FT 的实部/虚部/幅值、WT 的长表 TXT，以及四联图 PNG/PDF/SVG/TIFF。图中不把原生 FEFF μ 假称为实验归一化谱。后处理使用 Larch，FT 范围 3–12 Å⁻¹、Hanning 窗、dk = 1；WT 使用 k² 加权 Cauchy 变换。FT/WT 是对同一 χ(k) 的变换，不是额外独立证据。

比较 small 与 full 的谱形后再决定是否需要更大环境。此处检查的是有限分子内部截断；即使两者接近，也不代表已经验证缺失的对离子、溶剂或载体环境。未相移校正的 FT 峰位不能直接当作 W–O 键长，也没有约束其峰值必须出现在 1.5 Å。

## 4. 第二阶段：保留载体的四模型局域松弛

`catalyst_pilot/README.md` 给出具体操作。保留一种 W 替位假设和四个结构：

1. 羟基化载体，无 EG。
2. 邻近 Co 位点去质子化，无 EG。
3. EG 衍生烷氧基在 W 处配位。
4. EG 衍生烷氧基在邻位 Co 处配位。

W、邻近 Co/Fe、局部 O/H 和全部 EG 原子允许移动，远处相同的 34 个宿主原子固定。每个模型实际有 45–53 个可动原子。没有通过固定 Co 的方式强制其谱图不变。

与原十二模型相比，这一步减少的是模型数和优化自由度；平面波计算仍保留原来的晶胞和全部电子，因此每次 SCF 的成本并没有按比例下降。局域松弛通过后，关键构型需比较更大移动区域或全原子松弛。局部边界收敛没有验证前，不宜直接使用绝对吸附能做定量结论。

这四个模型不是 OCP/无 EG 1.6 V/有 EG 1.6 V 的已知稳态结构；没有恒电位/覆盖度/实验映射，不能自动换成这些工况图例。也不包含全部去质子化背景上的 EG 交叉构型，必要时应恢复这些对照。

## 5. 这个简化方案能回答什么

- 能快速建立有文献坐标来源的 W–O 配位参考，并计算真实 FEFF 输出。
- 能降低载体候选的初期筛选工作量，保留 W 与邻位 Co 的对照。
- 不能仅凭 PW₁₂ 或 WO₆ 参考，证明 W 是 EG 氧化的唯一活性位点。
- 当前有限 POM FEFF 输入使用中性原子电子势基准，未显式处理整个阴离子的 −3 电子数、对离子或溶剂。因此它是几何参考，不能用未经标定的边能位移定量指认 W 价态。
- 游离磷钨酸根的碱稳定性不能由该晶体模型保证；也不能从文献的 Fe 锚定 PW₁₂ 直接推出本体系在 3 M KOH 中存在同一物种。

用户参考的 CoFe/PW₁₂ 论文强调 PW₁₂ 经 Fe 锚定调节相邻 Co 活性中心：<https://doi.org/10.1038/s41467-025-60620-9>。借鉴它的合理方向是保留 W–O–Co/Fe 相邻环境，而不是去掉所有邻近金属后把剩余片段认定为已证实活性位点。

## 6. 耗时与优先级

建议先只提交四个有限 POM FEFF 任务。没有 DFT 优化，任务数也远少于原批次，但宽能量网格仍可能耗时；应以第一个真实任务的用时和内存为依据，不承诺分钟级完成。

本包附的四模型载体优化是可选后续，不会由参考计算脚本自动启动。先看参照结果，再决定是否值得进行局域松弛和后续 Co/Fe/W 计算。
