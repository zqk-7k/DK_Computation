# 可选的四模型载体局域松弛预筛选

本目录用于保留最低限度的载体和吸附位点对照。主流程中的完整磷钨酸根参考计算不依赖这里的 DFT。这里的四个 CIF 沿用上一包构建的候选结构，**尚未优化**，所有坐标和文件字节均保留，不把它们写成已优化结构。

## 保留的四个模型

| 模型 | 作用 | 原子总数 | 可动 / 固定原子 |
|---|---|---:|---:|
| `W_sub_Fe__hydroxylated__none` | 羟基化参考 | 80 | 46 / 34 |
| `W_sub_Fe__Co_deprotonated__none` | 相邻 Co 位点去质子化对照 | 79 | 45 / 34 |
| `W_sub_Fe__hydroxylated__EG_at_W` | EG 烷氧基配体与 W 配位 | 87 | 53 / 34 |
| `W_sub_Fe__hydroxylated__EG_at_Co` | EG 烷氧基配体与 Co 配位对照 | 87 | 53 / 34 |

全部为 W 替换原 Fe1 的候选模型，初始 W 第一重原子壳为六个 O。这是替位型结构假设，与原来的顶吸附 W 模型不同，也不等于完整磷钨酸根固定在 LDH 上。它们不预设 W 或 Co 的谱图变化方向。

相对于原来的十二模型，先保留一种锚定方式及四个对照。它们可用于初步检验 W–O 环境和 EG 在 W/Co 上的响应差别，但暂未包括去质子化背景上的两种 EG 构型，不能据此断言 EG 一定使 Co 恢复到羟基化状态。若机制判断依赖这一点，再补回相关交叉对照。

## 局域松弛规则

以稳定标签 `orig_0` 的 W 和 `orig_5` 的近邻 Co 为两个中心，4 Å 内的全部宿主原子可动；与可动 O 相连的 H 也可动，全部 EG 原子可动。其余宿主原子固定。四个模型共享相同的宿主标签掩码，因此不存在只固定某一个模型的 Co 来人为抑制其响应的做法。

`models/<模型>/structure.cif` 保存原候选；`local_relax_R4/<模型>/` 中有标准 XYZ、逐原子 TXT 和 JSON 掩码。TXT 同时给出零基索引、一基索引、稳定标签、元素、笛卡尔坐标和 QE 的三个 `if_pos` 标志。索引对应实际 CIF 解析后写入 QE 的顺序，不能与原始 CIF 文本行号混用。

这属于**有边界约束的局域松弛**。冻结边界可能影响配位和能量，不能把它写成全部原子松弛已收敛。减少模型数和自由度可能缩短筛选时间，但计算胞、原子数和平面波基组仍保留，每一步 SCF 的成本不会按可动原子数等比例降低。

## 输入生成

已准备四个结构和掩码。只有决定进一步优化载体模型时，才需要 QE 和赝势。使用与原补算包一致的官方 SSSP 1.3.0 PBE efficiency 六元素赝势，文件名和官方 MD5 存于 `docs/SSSP_1.3.0_PBE_efficiency.json`。

在安装了 pymatgen 和 NumPy 的 Python 环境中运行：

```bash
python catalyst_pilot/scripts/prepare_local_qe.py --pseudo-dir /actual/path/to/SSSP --output local_relax_R4
```

程序检查赝势文件及摘要，然后为四个模型写出 `qe.in` 和 `job.json`。绝对赝势路径请替换成超算上真实路径。若只查看输入格式，可加 `--allow-missing-pseudos`；生成结果会明确标为仅供输入检查，不能据此声称已计算。

QE 基准为自旋极化 PBE、U = 0、90/1080 Ry、2 × 2 × 1 k 点、固定晶胞、BFGS 局域松弛。外层冻结由 `ATOMIC_POSITIONS` 最后三列的 `0 0 0` 指定。自动在空真空区放置 slab 偶极修正，`eamp=0`，并不施加 1.6 V 电极电位。

输入需通过超算的实际调度系统运行 `pw.x -in qe.in`。本目录不另装或改动全局 QE，也不自动提交 DFT 作业；如已使用上一补算包的 QE 环境，可直接复用同一可执行文件和赝势。

## 验收和后续使用

运行后检查最后一次 SCF、BFGS 离子收敛和正常结束标志。局域松弛的力阈值应检查**可动原子**，并另外报告固定原子的剩余力；固定原子的力通常不为零，不能拿全原子最大力直接否定或宣布局域松弛收敛。还需检查最终原子没有进入偶极窗口，W 第一壳是否仍为 O，EG 是否仍在指定位置，以及是否出现不合理短键。

在用于定量论文结论前，至少对参考与关键吸附构型扩大到 5 Å 移动区域，并对必要构型做全原子松弛，比较键长、谱形和结论是否稳定。扩大区域需使用新目录：

```bash
python catalyst_pilot/scripts/prepare_local_qe.py --radius 5 --output local_relax_R5 --pseudo-dir /actual/path/to/SSSP
```

只有获得并检查真实优化输出后，才将其加入 FEFF 模型清单。未进行相位校正的 FT-EXAFS 约 1.5 Å 峰不能当成真实 W–O 键长，也不应成为结构调整目标。四种静态候选目前没有 OCP 或 1.6 V 的唯一对应关系；图例应使用结构/吸附态名称。
