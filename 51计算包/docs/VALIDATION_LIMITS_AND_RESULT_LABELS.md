# 验证范围、误差来源与结果标签

## 1. “接近实验”必须拆成可检验项目

计算谱与实验谱的相似性至少包括：峰数、峰序、化学位移、J 裂分、多重峰拓扑、线宽、相对强度、溶剂峰、基线和噪声。ORCA 静态量子化学主要提供屏蔽常数和 J 等分子性质；其余项目需要热力学、动力学、实验条件或显示模型。

因此本包不使用“一模一样”作为验收标准，而分别报告：

- 非交换 `1H` 和 `13C` 的逐峰误差、MAE/RMSE、最大误差和峰序；
- 交换性 NH/OH 的独立误差和可观测性状态；
- J 的误差、符号和多重峰拓扑；
- 构象、固定组成、方法、参考和校准不确定性；
- synthetic appearance 参数与实验采集参数是否独立获得。

## 2. 现实预期

刚性芳香体系在物种、构象、参考和溶剂处理正确时，非交换 `1H` 的峰序与位置可以较接近实验，工程目标常以零点几 ppm 评估；`13C` 常可达到结构鉴定所需的数 ppm 尺度。柔性药物、离子对、显式溶剂簇、互变异构体和强氢键体系的误差通常更大。

NH/OH 对温度、浓度、水含量、pH/pD、氢键和交换速率非常敏感，可相差数个 0.1 ppm，甚至超过 1 ppm。静态计算不能可靠预测其真实峰宽、峰高和是否因交换而消失。

这些是规划预期，不是对本 51 化合物的已验证误差承诺。只有独立实验集的预声明验证才能给出该协议在特定核种、溶剂和化学域内的性能。

## 3. 高级方法不等于实验真值

revDSD/pcSseg-3 和高层级基组文献可对理论参考提供很好的屏蔽常数表现，但气相高水平 benchmark 与溶液实验之间还隔着构象、溶剂、参考和动力学。revDSD 必须作为独立方法分支验证，而不是强制把 PBE0 峰移动到实验位置。

`NoFrozenCore`、更大基组、更多 CPU 或更严格阈值主要降低特定数值/电子结构近似；它们不能自动修复错误物种、错误溶剂组成、缺失构象或目标特异性校准偏差。

## 4. 三种结果标签

### PROVISIONAL

身份、盐型、质子化状态、实验条件、参考或特殊元素路线尚未确认。可以用于排错和敏感性分析，不能称为生产预测。

### CALCULATED

所有工作流门通过，得到可复现计算结果，但尚无独立、预声明实验验证。大多数包内最终文件应使用此标签。

### VALIDATED_WITHIN_SCOPE

只有在独立校准/验证集上通过预声明指标后使用，并必须写清核种、溶剂、温度范围、化学类别、方法版本和误差区间。该标签不能从一个苯甲酰胺样例外推到全部 51 个化合物。

## 5. CLEAN_CALCULATED 与 SYNTHETIC_APPEARANCE

`CLEAN_CALCULATED` 是科学主结果，包含数值位移、J、人口、分支和理想线表。

`SYNTHETIC_APPEARANCE` 是可选显示层，可以加入：

- Lorentzian/Gaussian/Voigt FWHM；
- DMSO-d6、D2O/HOD、内标和常见杂质峰；
- 固定随机种子噪声；
- 参数化基线、漂移和相对强度。

每项参数都要注明来源：`USER_SPECIFIED`、`INDEPENDENT_EXPERIMENT_LIBRARY` 或 `DISPLAY_ASSUMPTION`。禁止从目标实验谱逐点拟合后仍称作理论预测。

## 6. 最低验证设计

对协议进行真实验证时，应：

1. 预先划分校准集和盲测集；
2. 按核种、溶剂、交换性和化学类别分层；
3. 固定物种、构象、参考和回归规则后才查看盲测误差；
4. 同时报告 signed error、MAE、RMSE、最大误差、峰序和覆盖区间；
5. 对 PBE0、revDSD、两个 J 分支分别评估，不逐峰选择最好方法；
6. 保留失败化合物，不只报告成功例子。

## 7. 常见误判

- 溶剂峰和内标峰与化合物峰混淆；
- 把整条谱的 x 轴整体平移当作电子结构验证；
- 以目标实验峰拟合每个原子的修正量；
- 只比较图片相似，不比较逐原子 assignment 和人口；
- 用高峰遮蔽的视觉效果掩盖面积/核数不一致；
- 把一个显式水模型解释成真实样品含水量；
- 把 partial revDSD 覆盖与 PBE0 直接拼成一个谱。

所有图和 CSV 都应带方法、物种、固定组成、温度、参考、结果标签和 `CALCULATED — NOT EXPERIMENTAL` 水印/元数据。
