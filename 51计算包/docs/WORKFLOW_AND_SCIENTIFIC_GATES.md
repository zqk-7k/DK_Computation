# 完整工作流与科学门控

## 1. 目标与适用范围

本工作流用于 Figure 3 中除苯甲酰胺 `F3_005` 外的 51 个化合物。目标是得到可审计、可复现、适合结构鉴定的计算 NMR 结果，并显式报告构象、溶剂模型、方法和参考带来的不确定性。它不是“把理论谱修成实验谱”的流程，也不保证对任何分子达到逐峰完全一致。

默认模式为 `PRACTICAL_HIGH_ACCURACY`。只有下列情况才升级到 `ULTRA`：

- PBE0 与实验或独立校准出现不可解释的系统差异；
- PBE0 与 revDSD 的方法差异超过预先设定的容差；
- 峰顺序或结构判别结论对少数构象、质子化状态或溶剂 motif 高度敏感；
- 小而轻的体系需要评估 `NoFrozenCore`、更高覆盖率或更大基组的影响。

大分子、含重元素体系不能因为资源充足就自动升级到所有最高成本选项。首先必须证明该选项对目标性质有清楚的验证价值，并通过内存、基组和方法门控。

## 2. Stage 0：身份和实验条件锁定

每个计算分支必须先生成一个不可变的 condition/species lock。至少包括：

- Figure ID、结构哈希、InChIKey、带原子映射的 SMILES、立体中心；
- 净电荷、多重度、质子化/互变异构状态、游离体或盐；
- NMR 溶剂、温度、浓度、pH/pD、参考物、谱仪频率和请求核种；
- 显式溶剂组成和隐式溶剂模型；
- ORCA 版本、方法配置哈希和资源配置哈希。

未知实验字段可以暂用 `PROVISIONAL`，但不能空白后默认成“已确认”。修改身份、盐型、质子化状态、固定组成或方法时，必须产生新分支和新哈希。

## 3. Stage 1：固定组成的 GOAT 采样

每个显式溶剂化学计量是独立场景。常规 DMSO 方案的三个场景位置通常为：

1. 溶质 + DMSO 连续介质；
2. 溶质 + 2 DMSO + DMSO 连续介质；
3. 溶质 + 2 DMSO + 1 H2O + DMSO 连续介质。

D2O、盐和特定离子采用各自注册的三个固定组成场景。不同场景不能直接做 Boltzmann 混合，因为它们含有不同数目的分子；没有溶剂化学势或独立群体模型时，不存在可辩护的跨组成权重。

`2 + 3 + 5` 是三个位置的最低成功目标，不是固定总数，也不是构象收敛证明。候选起点按复杂度级别 `R/M/H/X` 预生成并保持 `HELD`。只按波次释放，待当前波全部到达终态后再评估。详见 `ADAPTIVE_GOAT_AND_CONVERGENCE.md`。

## 4. Stage 2：结构、立体和簇完整性门

GOAT 正常结束并不等于结构可用。每个结果必须依次通过：

1. 原子数、元素、键图和原子映射一致；
2. 立体中心、双键构型和必要的手性约束不变；
3. 电荷、多重度和盐/离子状态与分支一致；
4. 显式 DMSO/H2O/反离子数目不变，未发生错误共价连接；
5. 没有不合理短接触、碎裂或质子转移；若质子转移是研究对象，必须成为单独物种分支；
6. 使用溶质 RMSD、全簇 RMSD、相对能量和氢键/取向 motif 做 cluster-aware 去重；
7. 几何重复但由独立起点再次找到时，记作盆地复现证据，而不是简单丢弃。

只有通过门控的唯一结构才进入优化/频率步骤。所有拒绝都要保存原因和输入/输出哈希。

## 5. Stage 3：两层优化与频率

### 5.1 r2SCAN-3c 广覆盖层

对全部唯一、合格 GOAT 结构进行 r2SCAN-3c 优化和频率计算。它的作用是：

- 发现 GOAT 低层级势能面中的明显假极小值；
- 提供一致的初筛几何和 QRRHO 热力学校正；
- 建立初步构象权重和 motif 覆盖；
- 减少在高成本层对明显低权重重复结构的浪费。

这一层不自动成为最终 NMR 几何。

### 5.2 PBE0-D4 生产层

将覆盖每个固定组成分支至少 95% 初筛群体、全部必要 motif、全部近简并/峰顺序敏感结构的集合，使用：

`PBE0-D4/def2-TZVPP`, `RIJCOSX`, `VeryTightOpt`, `VeryTightSCF`, `DefGrid3`, 条件对应 CPCM。

对小刚性体系或 `ULTRA`，可对全部唯一结构做 PBE0 opt/freq。对柔性/离子/大显式簇，先做 95%+motif 集合，并以人口和峰位置稳定性决定是否扩展。不能按“只选最快完成的结构”构建集合。

虚频不能静默取绝对值。低于 -20 cm⁻¹ 的虚频默认重优化；-20 至 0 cm⁻¹ 必须检查振型、数值网格和簇的柔性运动。

## 6. Stage 4：QRRHO、去重和权重冻结

使用 `config/qrrho_and_conformer_policy.json` 的固定参数：100 cm⁻¹ 低频过渡、指数 4、1 mol L⁻¹ 标准态，以及 condition lock 中的温度。参数发生变化时必须改变 policy hash 并重做权重。

权重只在相同组成、电荷、多重度和物种内归一化。保存每个构象的：

- 电子能、热校正、`G_QRRHO`、相对自由能和归一化权重；
- 几何哈希、cluster ID、motif ID、复现次数；
- 删除/合并理由、有效样本量；
- 温度或阈值敏感性（柔性、离子和盐体系必需）。

## 7. Stage 5：PBE0 屏蔽常数基线

对最终合格的 PBE0 构象集合计算 `PBE0/pcSseg-3` GIAO 屏蔽常数。该分支是完整的默认基线。每个固定组成分别进行人口平均，并保留逐构象屏蔽常数，以便重新检查权重。

`pcSseg-3` 必须对所有元素和目标核种通过基组预检。含碘 `F3_006` 不走普通轻元素模板。

## 8. Stage 6：revDSD 独立验证分支

以最终 PBE0 权重选择代表结构，使每个固定组成的累计覆盖率至少为 95%，且每个关键 motif 至少有一个代表。对它们计算 relaxed-density `revDSD-PBEP86-D4/2021/pcSseg-3`。

重要规则：

- PBE0 和 revDSD 的 raw shielding 不拼接、不按人口混成一个方法；
- revDSD 覆盖不足 95% 时，只能标为 partial diagnostic，并补算结构；
- PBE0 和 revDSD 分别计算自己的同方法参考；
- `FrozenCore` 与 `NoFrozenCore` 是不同方法，不能隐式替换；
- `NoFrozenCore` 仅用于通过内存、元素、基组和参考测试的小/轻 `ULTRA` 分支；
- revDSD 成本更高，不代表它对所有核种和溶液条件自动更准。

revDSD 后仍有参考、校准、J、spin simulation 和输出分层，因此它不是流程最后一步。

## 9. Stage 7：参考与独立校准

每个 shielding 方法分支使用相同泛函、基组、密度处理、连续介质、相对论处理、ORCA 版本、SCF 和网格设置计算参考物。默认 TMS；D2O 的 DSS/TSP 只有在实验参考约定明确且计算协议锁定后才使用。

允许两种移位模型：

- 单位斜率：`δ = σ_ref − <σ_sample>`；
- 预声明线性模型：`δ = a + bσ`。

线性模型只能在独立校准集上交叉验证，随后冻结。禁止用目标样品峰拟合后再称作预测。NH/OH 等交换峰单独处理或从校准中排除。

## 10. Stage 8：J 方法门与 spin simulation

候选 J 方法为 `PBE/pcJ-3` 和 `PBE0/pcJ-2`。两条分支保持独立，通过跨化合物实验集比较有符号误差、MAE、耦合符号和多重峰拓扑后选择，不能平均。

非交换芳香/脂肪氢可在定义好的 spin system 上做各向同性自旋 Hamiltonian 模拟。静态计算得到的 NH/OH 耦合可留在表中，但由于快速交换、标量弛豫和线宽变化，默认不用于相干精细裂分。`13C` 默认输出质子去耦谱。

## 11. Stage 9：两层输出

先输出 `CLEAN_CALCULATED`：

- 逐原子屏蔽常数和化学位移；
- 参考和校准参数；
- 逐构象与平均结果；
- J、spin-system 定义和理想线表；
- 方法/场景/物种标签、不确定性和所有 gate receipt。

随后可选输出 `SYNTHETIC_APPEARANCE`：

- 指定或从独立实验库估计的 FWHM；
- 已知溶剂/水/内标峰；
- 明确标记的相对峰高模型；
- 固定随机种子的噪声和参数化基线。

第二层是显示模型，不是 ORCA 的第一性原理预测，也不能替换 clean calculated 层。

## 12. 最小可审计交付物

每个化合物至少要有：condition lock、GOAT 有效清单、结构门控、opt/freq 清单、QRRHO 表、shielding 与 reference 表、J 分支、spin simulation 输入、clean calculated CSV/图、可选 synthetic appearance CSV/图、完整 stdout/stderr、软件版本、资源记录和 SHA-256 inventory。
