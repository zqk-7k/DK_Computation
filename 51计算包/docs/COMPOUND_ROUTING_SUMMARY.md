# 51 个化合物的计算路由摘要

机器可读主表为 `config/compound_profiles.csv`。所有 51 个化合物都以三个固定组成位置的 `2 + 3 + 5` **最低成功目标**开始；差异主要体现在候选池上限、备用波次、特殊物种/元素门和核种可用性。复杂度级别不是准确度等级，也不要求把上限全部算完。

## R：刚性/低至中等风险（17 个）

`F3_001, F3_002, F3_003, F3_004, F3_006, F3_009, F3_012, F3_034, F3_035, F3_036, F3_037, F3_038, F3_039, F3_040, F3_043, F3_044, F3_052`

候选上限为 `4/6/10`。第一波 `3/4/7`，其余保持 held。虽然 R 级通常较快，`F3_006` 的碘路线、`F3_035/043/044` 的 D2O/无碳问题，以及 F/P 基组预检不能因“刚性”跳过。

## M：中等柔性或缔合（20 个）

`F3_007, F3_008, F3_010, F3_011, F3_013, F3_014, F3_015, F3_018, F3_024, F3_025, F3_026, F3_028, F3_029, F3_030, F3_041, F3_045, F3_046, F3_047, F3_049, F3_051`

候选上限为 `6/10/16`。第一波仍为 `3/4/7`。重点检查酰胺旋转异构、分子内/分子间氢键、侧链构象、P–N/P–O 周围构象以及显式 DMSO 竞争 motif。

## H：高柔性、离子/盐或强物种风险（12 个）

`F3_016, F3_017, F3_019, F3_020, F3_021, F3_027, F3_031, F3_032, F3_033, F3_042, F3_048, F3_050`

候选上限为 `8/12/20`。第一波仍为 `3/4/7`，后续波为 held。除构象外必须覆盖离子对、质子化、反离子位置、酰胺旋转、芳环堆积和不同氢键网络。`F3_016/017` 的 full salt 与 cation-only 分开；`F3_019/020/021` 先确认水溶液物种和 pD。

## X：异常尺寸/柔性或身份风险（2 个）

`F3_022, F3_023`

候选上限为 `10/16/24`，但不自动全算。`F3_022` 的甾体多羟基骨架需要对侧链、羟基网络和溶剂 motif 分区检查；`F3_023` 在身份确认前 fail-closed。X 级应优先评估 sampling 是否被低层级势能面偏置，而不是只增加相似起点。

## 溶剂路由

- DMSO-d6 主路由：45 个。三个位置通常为 continuum-only、`+2 DMSO`、`+2 DMSO+1 H2O`。
- D2O 主路由：6 个，即 `F3_019, F3_020, F3_021, F3_035, F3_043, F3_044`。采用 condition table 中的三个固定水合簇大小，每个大小分别运行最低目标 2/3/5。不同水合数不做 Boltzmann 混合。

DMSO/H2O 数目是预声明的 microsolvation 模型，不是从样品实测水含量推导。实验元数据确认后可以增加 sensitivity branch，但不能悄悄改变主分支。

## 核种路由

- 常规含碳体系：`1H` 与 `13C`；交换性 H 单独标注。
- `F3_003, F3_037, F3_039`：可选 `19F`，需要独立参考和 C–F/H–F J 路由。
- `F3_043`–`F3_052`：可选 `31P`，需要独立参考和 P 耦合路由。
- `F3_035, F3_043, F3_044`：没有碳，`13C = NOT_APPLICABLE`；D2O 中普通 analyte `1H` 也可能因快速交换基本不可见。

## 何时提升候选上限

只有在当前完整波次未通过盆地复现、motif 覆盖、新盆地、峰序或人口加权位移稳定门时才释放下一波。若失败来自身份、起点摆放、错误质子化、基组或文件系统，应先修复原因，而不是将其解释为“GOAT 数量不足”。
