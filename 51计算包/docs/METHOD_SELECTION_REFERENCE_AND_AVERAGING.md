# 方法选择、参考和平均规则

## 1. 为什么默认不是“所有结构直接 revDSD/NoFrozenCore”

高成本方法可能降低某些屏蔽常数的理论误差，但溶液 NMR 的总误差还包含物种、构象人口、显式溶剂选择、参考、温度、交换和实验条件。对错误物种或错误人口使用更昂贵的方法不会自动得到更真实的谱。

因此默认流程先保证构象和热力学覆盖，再建立完整 PBE0 基线，最后用 revDSD 独立检查高人口集合。此设计同时保留方法比较和可完成性。

## 2. 两层 opt/freq 的职责

`r2SCAN-3c` 用于广覆盖、去除明显假极小值和形成初步人口。`PBE0-D4/def2-TZVPP` 用于高权重、motif 完整的生产几何和频率。两个层级的热校正与电子能来源必须在表中明确，不能无说明地拼接。

默认 PBE0 集合覆盖至少 95% r2SCAN-3c 初步人口，并保留所有必要 motif 和近简并结构。小刚性或 `ULTRA` 可全覆盖；柔性体系通过稳定性门决定扩展。

## 3. 屏蔽常数分支

### PBE0 基线

`PBE0/pcSseg-3` 在最终 PBE0 构象集合上全覆盖，形成默认、完整的计算分支。其主要价值是稳定、可扩展，并可在 51 个体系上保持统一协议。

### revDSD 验证

relaxed-density `revDSD-PBEP86-D4/2021/pcSseg-3` 至少覆盖每个固定组成内 95% 的 PBE0 人口及全部关键 motif。输出一条独立的 revDSD 平均谱或方法差异报告。

如果覆盖不足，不得用 PBE0 raw shielding 填补缺口。正确做法是补算 revDSD，或明确标为 partial diagnostic。`FrozenCore` 和 `NoFrozenCore` 是不同方法；默认使用可部署、可参考的 frozen-core 分支，NoFrozenCore 仅在小/轻体系的 `ULTRA` 诊断中开启。

## 4. 人口平均的边界

允许平均：同一固定分子组成、同一物种、电荷、多重度、温度和方法分支内的构象。

不允许直接平均：

- continuum-only、`+2 DMSO`、`+2 DMSO+1 H2O`；
- 游离碱/酸、不同质子化态或互变异构体；
- cation-only 与 full salt；
- PBE0 与 revDSD raw shielding；
- FrozenCore 与 NoFrozenCore；
- 不同 ORCA 版本或相对论路线。

跨组成混合需要独立定义的溶剂化学势/平衡常数和相同标准态。没有这些证据时，只并排报告场景敏感性。

## 5. 同方法参考

默认化学位移为：

`δ_sample = σ_reference − Σ_i w_i σ_i`

参考计算必须匹配样品分支的泛函、基组、密度处理、溶剂模型、相对论/图片变换、SCF/网格和 ORCA 版本。PBE0 和 revDSD 各自使用自己的参考。若实验在 D2O 中以 DSS/TSP 参考，必须把实验参考约定和计算参考转换写入 condition lock。

## 6. 经验校准的正确使用

允许预声明 `δ = a + bσ`，但 `a,b` 必须来自独立校准集的交叉验证。训练范围要注明核种、溶剂、方法和化学类别。目标化合物不能既用于拟合又用于声称盲预测。

交换性 NH/OH 受氢键、酸碱平衡、水含量和交换速率控制，应单独校准或不纳入普通非交换 `1H` 回归。

## 7. J 耦合

`PBE/pcJ-3` 与 `PBE0/pcJ-2` 是两个候选分支，不做平均。用跨化合物、有实验 J 值的校准集比较耦合符号、有符号偏差、MAE 和最终多重峰拓扑后选择。若不同键型表现不同，可以形成预声明的键型路由，但不能逐个目标峰事后选择“更像实验”的方法。

## 8. 结果解释

PBE0 与 revDSD 一致，说明方法依赖较小，不代表溶剂/物种/实验效应已解决。两者分歧大时，应先检查人口、参考、密度处理、基组和相对论设置，然后再考虑 `ULTRA`。任何方法分支都必须同时报告构象和场景不确定性。
