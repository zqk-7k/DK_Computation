# 真实谱图校准：当前可用内容与边界

已只读检查 `${LOCAL_SOURCE_NOT_INCLUDED}\处理过的谱图`：共 27 个 `.mnova`、27 个 PDF、26 个 TIFF，以及一个开放数值谱 `1-1-C.csv`。没有发现独立的 Bruker `fid/ser/acqus/procs` 目录。

`.mnova` 容器中可以找到采集和处理元数据；但 `.mnova` 文件的存在不等于原始 vendor FID 已经完整保留。当前只能把 `1-1-C.csv` 定义为“处理后 XY 数据”，不能称为 FID。`scripts/exportActiveSpectrumBundle.qs` 会通过 Mnova API 检查 `fidCount()`：只有返回大于 0 并成功导出复数时域点时，才记录为“Mnova 可导出的内部 FID”。这仍需与原始实验目录校验，不能自动改称原始 Bruker FID。

苯甲酰胺 `1-1-H/C` 已用于第一轮外观校准。重要事实是：真实 ^1H 与 ^13C 的采集温度、扫描数、加窗和相位参数不同，因此二者不能复用同一条噪声、同一线宽或同一基线。当前 ^13C 有开放 XY，可以数值估计噪声与线宽；^1H 暂时只能使用采集元数据和 PDF/TIFF 外观，等待 Mnova 数值导出。

其余样品可以用于建立“分布”，例如 DMSO 残峰强度、水峰强度、^1H/^13C 噪声、基线和线宽的样品间变化。不得逐个复制一条真实谱的噪声，也不得为了视觉相似而加入没有样品历史依据的匿名杂质峰。

F3_019、F3_020、F3_021、F3_035、F3_043 和 F3_044 在该文件夹中没有一一对应的开放原始谱，因此本目录不能替代它们各自的 pD、浓度、温度和采集记录。
