二、资源配置
balanced（默认）：每节点4worker，各8分配CPU/28500MB。GOAT与预筛实际8MPI，
下游实际4MPI，所以同时下游通常16MPI；这不等于已测得100% CPU利用率。
large_memory：2worker，各16CPU/57000MB，适合实测需要更多内存的阶段。
branch_parallel：2worker，各16CPU/57000MB，每个分支最多两个独立DFT任务并行；
子任务使用独立进程、独立CPU亲和及各半内存预算。同一构象的上下游依赖不并行跨越。
预筛8×2500MB、GOAT8×2000MB均须通过每槽内存余量检查；MaxCore仍不是进程RSS硬限制。
更换profile需要相应pilot；不在运行中修改已冻结的科学输入。默认未设置单分支并行GOAT。

五、空间和恢复
空间、inode或用户配额不足属于WAITING_STORAGE；不因这些等待把计算节点判坏。
明确的本地只读挂载才进入节点隔离。共享盘可写/空闲检查不等于个人额度核实。
本轮quota -s未返回有效额度；用户提及的专用配额工具权限限制仍需平台侧解决，
不能把共享文件系统df空闲量冒充个人可用空间。正式扩容前应取得有效额度信息。

修复完成后的受控恢复（默认计划；加--execute才改变状态）：
  python scripts/operations.py resume --species 实际物种ID --reason '具体修复及证据'
  python scripts/operations.py resume --species 实际物种ID --reason '具体修复及证据' --execute
它核对当前领取/锁、冻结配置和工作副本，记录resume_history，再返回SAMPLING或DFT。
它不批准科学收敛，问题未解决会重新报告。已有完成谱图波次需--expand启动真实扩展；
不重放同一波次伪造独立采样。旧unblock遇到phase=REVIEW会明确提示使用resume。
