工作2-计算资源包-（5）
用途：64个18O标记产物的计算NMR工作流。不是实验谱图，也未完成实际量子化学计算。

本版最重要的定义
3 / 5 / 10 / 15 是最终DFT优化、频率检查、结构复核及去重后，可用于NMR的独立稳定构象目标下限。
它们不是GOAT起点数，不是GOAT原始结构数，也不是预筛DFT的输入数。
R较刚性简单：3；M中等柔性：5；H较柔性/多氢键布局：10；X复杂药物/高柔性：15。
64个产物保留66个独立结构分支；E11、E22的两种分支分别达到目标，不跨非对映异构体凑数或加权。
本版计划值：66个产物分支合计526个目标稳定构象，TMS目标3。以上不是实际获得的结果或保证输出数量。

统一溶剂与温度
每个簇：产物 + 2 DMSO-d6 + 1普通H2O。GOAT外围ALPB(DMSO)，DFT外围CPCM(DMSO)，298.15 K。
这是可统一实施的计算模型，不代表已证实所有64种样品的真实第一溶剂壳都是2:1，也不代表真实水浓度。
不自动交换产物的OH/NH氢；盐型、质子化、互变异构与实验立体构型仍按原有记录待核实。
无需先计算纯连续介质或仅2DMSO分支；需要时可独立做敏感性对照，不能跨组成混合Boltzmann加权。

自动推进
完整GOAT批次结束 → 来源/结构检查 → 合并去重 → 低能量与结构代表性选择 → r2SCAN预筛 → PBE0优化/频率 → 最终稳定构象去重计数。
未达到最终稳定目标：优先补充已搜索的保留候选，再释放更多GOAT起点。不得在GOAT刚找到第N个结构时结束正在运行的批次。
达到目标：进入屏蔽常数、J耦合及探索性谱图；可保留多于目标的相关稳定构象，不强行裁成恰好N个。
目标只是首批NMR的最低数量，不是搜索充分或谱图准确的证明。随后扩展波次，比较构象覆盖、重复发现及NMR变化。
默认每结构先释放7个GOAT起点，后续每批最多4个；1020个既有起点中，469初始释放，551保留。
初批候选送DFT预算默认为最终稳定目标的2倍。这只是补偿优化合并的初始安排，可出现不足，不能保证产出N个。
有限起点池耗尽仍不足：报告缺口并等待复核；绝不复制结构、自动降低目标或用高能无关结构凑数。
DFT失败/超时/虚频：保留证据并暂停相关推进，见docs/异常处理与人工复核.txt；不自动删除失败候选。
即使人工接受某个带虚频结构作近似，它也不能计入本版的“无负频稳定构象”目标。

运行入口（在此目录内）
python workflow.py auto-plan
python workflow.py auto-step --species F2_E01_rep_R__DMSO
前两条不启动QM。auto-step可准备状态与后续输入，因此不要在原始交付副本中做生产计算。
实际自动运行示例（路径改成服务器上已配置的ORCA、otool_xtb及专用ASCII临时目录）：
python workflow.py auto-run --all --execute --acknowledge-models --orca /opt/orca/orca --xtb /opt/orca/otool_xtb --scratch-root /scratch/work2_v5
此便携入口按步执行，不负责为一万核配置队列或并发；可按结构分别启动，外部调度使用明确的已释放任务清单，不扫描整个目录提交。
每次调用最多启动一个任务；失败不会自动覆盖重跑。默认最多10000步，可用--max-steps调整；轮询间隔--poll-seconds不超过60秒。
原有prepare/advance/collect及手工审查入口保留；v5直接advance同样执行最终稳定构象门槛。

结果与人工判断
非交换性1H变化0.05 ppm、13C变化0.5 ppm仅作扩展波次的观察参考，不是强制准确度标准。
J耦合/裂分模式、主要溶剂布局、重复发现及样品状态仍须审阅；软件不会伪造“人工批准”或自动签发科学收敛结论。
同一结构各波次使用不可变独立工作目录，累计重算，避免源文件改变后复用失效结果；这增加计算成本，含匹配TMS重算。
图4六个药物J方法仍为PBE/pcJ-3，其他按原有两方法基准；不含revDSD。线宽默认H 1 Hz/C 2 Hz，可只改显示不重跑QM。
