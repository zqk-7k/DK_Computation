# Supercomputer execution contract

The user requests completion of this supplementary structure-based XAS workflow. Read README.md, config.json, docs/STRUCTURE_AND_METHOD_LIMITS.md, docs/SOFTWARE_AND_EXECUTION.md, and docs/FEFF_ENERGY_WINDOW.md first. Routine discovery, user-space installation, candidate construction, scheduler submissions within configured resources, recovery, postprocessing, and packaging are authorized. Do not stop after making a plan or inputs.

1. Preserve structures_original and their hashes. The previous structures were optimized, but all new substitutional/adsorption candidates are UNOPTIMIZED hypotheses. Never present them as experimentally established structures or simply rename them OCP/1.6 V.
2. Inspect actual platform modules, MPI, queue/account rules, memory and time limits. Existing site software is preferred. Download only official QE/FEFF/SSSP sources; verify pinned versions and digests. No sudo, no secrets in files, no heavy calculations on login nodes.
3. Read all candidate atom-change metadata. Both W-sub-Fe and W-sub-Co hypotheses, both hydroxylation backgrounds, and EG-at-W/EG-at-Co controls must remain in the analysis. Do not silently select the candidate that best matches the intended conclusion.
4. Run real Quantum ESPRESSO geometry optimization. Fix lattice only; no constraints designed to keep Co unchanged or force W-O distances. Normal process exit alone is insufficient: validate SCF, ionic convergence, atomic forces, stoichiometry and output hashes. If failed, diagnose and revise justified settings in a new run directory; preserve the failed attempt.
5. PBE/U0 is a new screening baseline, not inherited VASP settings. Before publication-level mechanistic interpretation, perform and document cutoff/kmesh, spin/U, vacuum/solvation sensitivity as appropriate. Never assert that standard SSSP recommendations establish system-specific convergence. Do not infer exact electrode potentials from neutral static structures.
6. Audit relaxed W neighbours at multiple cutoffs. If an all-O hypothesis is lost, retain and identify this result; do not remove Co/Fe/C neighbours or move peaks to pass the audit. The default continues calculating these alternatives with explicit audit metadata. A stop policy is configurable.
7. Run representative FEFF radius screens for hydroxylated and EG-bound models. Inspect SCF logs as well as numerical spectral differences. If convergence fails, increase justified parameters and resources; do not loosen tolerances solely to achieve the desired plot. Verify the actual W xmu photon energy covers10100-10300eV. No padding/extrapolation or independent peak alignment.
8. Compute all intended W/Co/Fe absorbing sites and average signed chi before FT/WT. FT R is phase uncorrected; a peak near1.5A is not a1.5A W-O bond. Do not add fitted coordination numbers/confidence intervals without experimental fitting.
9. Produce all TXT and PNG/PDF/SVG/TIFF exports. Validate every requested comparison is present and full-site averaged. Inspect representative images at final size; report actual font. The three-state plot labels describe structural models until a separate defensible potential mapping exists.
10. Spectral changes must come from the engine, never manual adjustment. Unchanged W or changed Co under EG are valid possible results. Elemental spectral response alone cannot prove exclusive W activity or exclude cooperative Co/Fe sites.
11. Honor configured parallelism and allocation. Real prior FEFF jobs took hours, not minutes; wide grids can be slower. Benchmark before increasing resource use or walltime. Query existing arrays before resubmitting. Preserve and report failed jobs and incomplete comparisons.
12. Finish with deliverables/CALCULATED_W_O_SUPPLEMENT_*.zip, raw native inputs/outputs, candidates and relaxed structures, settings/software provenance, TXT/images, model/coordination audits, methods and limitations. Report only calculations actually completed. Package preparation and mock tests are not FEFF/DFT execution.

Start with `bash run_supplement.sh auto` after loading actual platform modules. Read and fix real errors, rerun checks, and continue autonomously through routine recoverable problems. If scientific assumptions are not validated, preserve explicit labels rather than inventing a favorable conclusion.
