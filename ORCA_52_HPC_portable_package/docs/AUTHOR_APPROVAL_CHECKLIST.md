# 作者审核清单

在启动逐个 ORCA 计算前，请审核下列项目。当前默认值都只是建议，不是已核验的实验事实。

- [x] 作者已确认：F3_019、F3_020、F3_021 以 D2O 为主条件，DMSO-d6 仅作为样品完全溶解时的第二条件；F3_035、F3_043、F3_044 使用 D2O。
- [ ] 为 F3_019、F3_020、F3_021、F3_035、F3_043、F3_044 补充实际 pD、浓度和测试温度；在此之前离子化情景必须分开输出。
- [ ] 每条谱使用自己的真实温度。苯甲酰胺本地记录为 ^1H 312.609 K、^13C 304.0651 K，不再把 298.15 K 写成该谱的实测温度；没有记录的计算才可把 298.15 K 明确标为假设值。
- [ ] 默认浓度范围见 CSV；正式运行时以真实称样质量和 0.60 mL 溶剂体积覆盖。
- [ ] DMSO-d6 的 ^1H 背景使用 2.500 ppm 残余 DMSO-d5 和名义 3.33 ppm 水；水峰允许随样品改变，不强制 52 张谱完全相同。
- [ ] DMSO-d6 的 ^13C 背景使用约 39.52 ppm、J_CD 约 21 Hz 的 septet；不画成所有样品都一样高的单峰。
- [x] 苯甲酰胺真实处理谱已完成第一轮外观校准：^1H 显示 S/N 约 1.6×10^4–2.1×10^4，^13C 最大产品峰 S/N 约 1.15×10^3；两种核不再共用同一噪声模型。
- [ ] 保存并关闭当前 Mnova 后，使用本地导出脚本检查各 `.mnova` 的 `fidCount()`；只有实际导出的复数时域点可称为 Mnova 内部 FID，仍需原始 Bruker 目录和校验和才能称为原始 vendor FID。
- [ ] 主谱不随机虚构未知杂质峰。只有实验记录/空白支持的残留溶剂、试剂或硅脂等才加入，并逐峰标来源。
- [ ] 输出始终分为计算核心谱和实验外观合成谱；所有合成谱永久标记 `NOT EXPERIMENTAL`。
- [ ] J 耦合先在代表集比较 PBE/pcJ-3 与已跑通的 PBE0/pcJ-2，再统一锁定全批方法。
- [ ] F3_006 增加碘的相对论敏感性分支；F3_003/037/039 单独校准 ^19F；F3_043–052 单独校准 ^31P。
- [ ] 盐和两性离子分别输出接触离子对、溶剂分离和质子化情景；没有 pH/pD 或物种比例时不强行混成一张“唯一正确”谱。

## 最有价值的校准文件

如能提供以下任一项，实验外观会明显更接近本实验室的真实谱：

1. 同一台仪器、同一探头、同一采集模板下的 DMSO-d6 空白 FID/TopSpin 文件夹；
2. 苯甲酰胺真实 FID；
3. 一个盐型化合物和一个含 P 化合物的真实 FID；
4. 对应 acqus/procs 或仪器导出的完整采集和处理参数。
